# Dynamic Array Rubik's Cube Simulator

A Java-based project developed for **Data Structures and Algorithms (DSA)**. This project explores the use of dynamic arrays in implementing a Rubik's Cube simulator.

## About the Project

The Dynamic Array Rubik's Cube Simulator is a programming project that combines data structures and problem-solving concepts through a Rubik's Cube simulation.

It demonstrates the application of Java programming and dynamic array concepts in organizing and manipulating data.

## Technologies Used

- **Programming Language:** Java
- **IDE:** Eclipse
- **Data Structure:** Dynamic Array
- **Version Control:** Git and GitHub

## How to Run the Project

1. Clone or download this repository.
2. Open Eclipse IDE.
3. Select **File → Import → Existing Projects into Workspace**.
4. Browse and select the downloaded project folder.
5. Open the `src/finalproject` package.
6. Locate the Java class containing the `main()` method.
7. Right-click the class and select **Run As → Java Application**.
